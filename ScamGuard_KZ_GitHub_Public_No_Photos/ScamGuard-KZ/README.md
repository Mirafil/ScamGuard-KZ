# ScamGuard KZ — Educational Antifraud MVP

**Команда:** Абдрашитова Альмира, Макулбаева Адель · группа JUR-2403IJ · 3 курс, факультет журналистики.

ScamGuard KZ — университетский прототип оценки риска банковского перевода **до списания средств**. Банк получает Risk Score 0–100, объяснение причин и рекомендацию ALLOW / VERIFY / HOLD. Прототип включает конструктор операций, синтетическую карту исторических связей и Validation Lab.

> **Важно:** действующая версия — **rule-based MVP**, а не обученная ML/AI-модель. Не подключена к реальным банкам, не предназначена для обработки персональных банковских данных, качество на реальных операциях не доказано. Все примеры синтетические.

## Самый простой запуск

Откройте `index.html` в браузере. Он работает автономно без Python.

## Как повторить тестирование

Нужен Python 3.10+; для тестирования **не требуются сторонние библиотеки**.

```bash
python tools/reproduce_validation.py
python -m unittest discover -s tests -v
```

Скрипт пересоздаёт датасет и отчёт. Результат при пороге тревоги **40**: из 600 синтетических случаев TP=88, FP=171, FN=40, TN=301; Recall=68.75%, FPR≈36.23%. Это не независимая оценка на банковских данных и не доказательство конкурентного превосходства.

## Локальный учебный API (необязательно)

```bash
python server.py
```

Откройте http://127.0.0.1:8765. Для запроса `POST /v1/transaction/check` требуется предварительно установить переменную окружения `SCAMGUARD_API_KEY` со своим локальным значением (образец в `.env.example`). `.env.example` **не загружается автоматически**, он только показывает название переменной. Для Windows PowerShell перед стартом сервера:

```powershell
$env:SCAMGUARD_API_KEY = 'some-long-random-local-secret'
python server.py
```

Сервер работает только локально по HTTP. **Не публиковать как настоящий банковский сервис.** Локальная база SQLite создаётся при старте и исключена из GitHub через `.gitignore`.
